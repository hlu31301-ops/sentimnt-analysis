# 02. UI/UX 디자인 구현 지침

첨부된 레퍼런스 이미지(`스크린샷(80).jpg`)의 **맑고 청량한 하늘색·화이트 톤과 넓은 여백, 감성적인 타이포그래피**를 바탕으로 UI를 구성합니다.

## 1. 구현 범위
- 디자인 시스템(컬러, 폰트, 여백, 둥근 모서리) 정의 및 `public/style.css` 작성
- 반응형 레이아웃(모바일 및 데스크톱 화면 대응) 구현

## 2. 디자인 토큰 (Design Tokens)
- **배경색 (Background)**:
  - 전체 배경: `#F4F8FD` (아주 연한 하늘빛 화이트)
  - 카드 배경: `#FFFFFF` (순백색) 또는 반투명 화이트 `rgba(255, 255, 255, 0.85)`
  - 히어로 상단 그라데이션: `linear-gradient(135deg, #E0F0FF 0%, #F4F8FD 100%)`
- **포인트 컬러 (Accent)**:
  - 메인 블루: `#4A90E2` (버튼, 강조 텍스트)
  - 호버 블루: `#357ABD`
- **감정 상태별 컬러**:
  - 긍정(Positive): `#2E7D32` (배경 `#E8F5E9`)
  - 부정(Negative): `#C62828` (배경 `#FFEBEE`)
  - 중립(Neutral): `#475569` (배경 `#F1F5F9`)
- **텍스트 컬러**:
  - 기본 제목: `#1E293B` (딥 네이비)
  - 본문/설명: `#64748B` (차분한 그레이)
- **타이포그래피**:
  - 웹폰트 `Pretendard` 또는 `Noto Sans KR` 사용 (CDN 연결)
  - 히어로 타이틀: 굵고 시원한 크기 (`2rem ~ 2.5rem`), 자간 `-0.02em`
- **모서리 및 그림자**:
  - 카드 모서리: `border-radius: 20px`
  - 입력창/버튼 모서리: `border-radius: 12px`
  - 그림자: `box-shadow: 0 10px 30px rgba(74, 144, 226, 0.08)`

## 3. 레이아웃 구성
1. **상단 헤더**: 심플한 로고/서비스명 배치 (과도한 메뉴 생략)
2. **히어로 섹션**: 레퍼런스 이미지처럼 감성적인 문구("생각에 형태를, 감정에 색을.")와 간단한 서비스 소개
3. **메인 분석 카드 (중앙 정렬, 최대 너비 680px)**:
   - 텍스트 입력 영역 (`textarea`)
   - 글자 수 표시 및 '감정 분석하기' 버튼
4. **결과 카드 (분석 완료 시 부드럽게 표시)**:
   - 감정 뱃지 (긍정/부정/중립)
   - 신뢰도 백분율 숫자 + 애니메이션 프로그레스 바
   - 분석 이유 텍스트 박스
5. **오류 메시지 영역**: 분석 카드 하단에 빨간색 계열의 부드러운 알림 박스로 표시 (평소에는 숨김)

## 4. 완료 및 검증 기준
- 데스크톱(1200px 이상)과 모바일(375px) 화면에서 가로 스크롤이 생기지 않고 중앙 정렬이 유지되어야 합니다.
- 버튼에 마우스를 올렸을 때(Hover) 색상 변화와 부드러운 전환(`transition: 0.2s`)이 작동해야 합니다.
