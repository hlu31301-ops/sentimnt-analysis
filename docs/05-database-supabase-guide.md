# 05. Supabase 데이터베이스 연동 지침

## 1. 구현 범위
- Supabase 테이블 생성 SQL 스키마 제공
- 백엔드에서 감성 분석 완료 후 결과를 Supabase에 저장하는 로직 구현

## 2. 데이터베이스 스키마 (SQL)
비전공자 사용자가 Supabase 대시보드(SQL Editor)에 그대로 복사해서 실행할 수 있도록 아래 SQL을 안내하고 프로젝트 내 `schema.sql` 파일로도 저장해 두세요.

```sql
CREATE TABLE sentiment_logs (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  input_text TEXT NOT NULL,
  sentiment VARCHAR(20) NOT NULL,
  confidence INTEGER NOT NULL,
  reason TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
```

## 3. 백엔드 연동 규칙
- OpenAI API로부터 감성 분석 결과를 성공적으로 받은 직후, Supabase 클라이언트를 이용해 `sentiment_logs` 테이블에 데이터를 `insert` 합니다.
- **중요**: 만약 Supabase 저장 중 일시적인 오류가 발생하더라도, 사용자에게는 감성 분석 결과 자체는 정상적으로 반환하고 서버 콘솔에만 DB 저장 실패 로그를 남기도록 구현하세요. (핵심 기능 방해 금지)

## 4. 완료 및 검증 기준
- 감성 분석을 1회 실행한 후 Supabase 대시보드의 Table Editor에서 `sentiment_logs` 테이블에 새로운 행(Row)이 정상적으로 추가되었는지 확인합니다.
